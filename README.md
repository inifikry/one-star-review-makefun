# One-Star Review of Something Essential

A deadpan one-star review of gravity, the everyday essential everyone relies on and nobody can return.

> One star. Gravity has perfect attendance and never takes a day off, yet it always drops my phone screen-first onto concrete.

The grievance is the sharp, true one everyone recognises: gravity never fails, never rests, and still manages to land the phone screen-first on concrete every single time. The complaint is read straight, and the sting arrives in the last few words.

`main.py` writes the exact review to `/output/entry.txt`.
